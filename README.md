# 🐾 Floating Cat Desktop Companion (플로팅 고양이 펫)

윈도우 바탕화면 최상단에서 자유롭게 돌아다니고 상호작용할 수 있는 투명 플로팅 데스크톱 펫입니다.

---

### 🚀 실행 방법 (즉시 실행 가능)

1. **방법 1 (가장 간편)**:
   * [run.bat](file:///c:/dev/PLAYGRAND(test_center)/floating_test/run.bat) 파일을 **더블클릭**하면 콘솔 창 없이 즉시 실행됩니다.
2. **방법 2**:
   * [floating_cat.pyw](file:///c:/dev/PLAYGRAND(test_center)/floating_test/floating_cat.pyw) 파일을 **더블클릭**합니다.

---

### ✨ 주요 기능 및 인터랙션

1. **최상단 투명 플로팅 (Always on Top)**
   * 배경이 완전히 투명하며, 다른 모든 창보다 위에 표시됩니다.
   * 고양이 몸체 외의 투명한 영역은 바탕화면/다른 창 클릭이 그대로 통과됩니다.

2. **자동 걷기 및 그루밍 루틴**
   * **걷기**: 1초~10초 동안 무작위로 천천히 걸어 다니며, 화면 끝에 닿으면 부드럽게 반대 방향으로 돌아섭니다.
   * **그루밍**: 멈춰 서서 10초~60초 동안 무작위 시간 동안 얌전하게 앉아 앞발을 핥으며 얼굴을 단장합니다.

3. **뒷덜미 잡기 & 관성 스윙 물리 (Drag & Swing)**
   * **좌클릭**: 마우스로 고양이를 클릭하면 손으로 **뒷덜미를 콕 집어 들어 올린 모습**으로 전환됩니다.
   * **드래그 이동**: 마우스를 빠르게 움직이면 이동 방향과 가속도에 맞춰 몸이 기울어집니다.
   * **정지 시 흔들림**: 드래그 도중 마우스를 멈추면 **진자 운동(Damped Pendulum) 물리**가 작동하여 몸이 좌우로 대롱대롱 흔들리다가 서서히 멈춥니다.
   * **놓기(낙하)**: 공중에서 마우스를 놓으면 중력에 의해 바닥으로 사뿐히 떨어져 착지 후 다시 걷기/그루밍을 시작합니다.

4. **우클릭 종료**
   * 고양이 몸체를 **마우스 우클릭**하면 깔끔하게 즉시 종료됩니다.
